[Advisor tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)Lets a faster executor model consult a more capable advisor model mid-generation for a plan or a course correction.[Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)Reusable packages of instructions, metadata and optional scripts that Claude uses automatically when they are relevant to a task.Part of Agent Skills: [Custom Skills](https://platform.claude.com/docs/en/build-with-claude/skills-guide#managing-custom-skills)Skills you write and upload to your workspace.Part of Agent Skills: [Pre-built Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview#pre-built-agent-skills)Anthropic’s pre-built skills for PowerPoint, Excel, Word and PDF files.[Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)Processes many Messages API requests asynchronously in one batch, at half the standard price.[Browser and computer use SDK toolsets](https://platform.claude.com/docs/en/agents-and-tools/tool-use/browser-use-sdk)Classes in the Python and TypeScript SDKs that connect the browser use or computer use tool to a browser or desktop that you supply.[Browser use tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/browser-use-tool)Lets Claude navigate, read, and interact with webpages in your own browser environment.[Citations](https://platform.claude.com/docs/en/build-with-claude/citations)Claude’s answers about your documents cite the exact passages that support each claim.[Classifier refusals](https://platform.claude.com/docs/en/build-with-claude/refusals-and-fallback)Safety classifiers on some models can decline a request; the decline comes back as a normal response, not an error.Part of Classifier refusals: [Client-side fallback](https://platform.claude.com/docs/en/build-with-claude/refusals-and-fallback#client-side-fallback)A middleware in the Claude SDKs that retries a refused request on the fallback models you list.Part of Classifier refusals: [Fallback credit](https://platform.claude.com/docs/en/build-with-claude/fallback-credit)Bills a retry of a refused request on another model as if the conversation had been on that model from the start, so you do not pay the prompt-cache write twice.Part of Classifier refusals: [Server-side fallback](https://platform.claude.com/docs/en/build-with-claude/refusals-and-fallback#server-side-fallback)The API retries a refused request on a fallback model within the same call and returns one response.[Computer use tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)Gives Claude screenshot, mouse, and keyboard control of a desktop environment.[Custom tools](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools)Tools you define with a name, description and input schema. Claude asks to call them; your code runs them and returns the result.[Data residency](https://platform.claude.com/docs/en/manage-claude/data-residency)Controls for where model inference runs (inference geo) and where data is stored at rest (workspace geo).[Effort](https://platform.claude.com/docs/en/build-with-claude/effort)A setting that controls how many tokens Claude spends on a response, trading thoroughness for token efficiency.Part of Effort: [Per-message effort](https://platform.claude.com/docs/en/build-with-claude/effort#change-effort-mid-conversation-beta)Changing the effort level for later turns of a conversation with a per-message `output_config`, which keeps the prompt cache.[Fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode)Up to 2.5 times more output tokens per second from supported models, at premium pricing.[Files API](https://platform.claude.com/docs/en/build-with-claude/files)Upload a file once and refer to it by `file_id` in later requests, and download files that skills or the code execution tool create.[MCP connector](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)Connect Claude to remote MCP servers so it can call their tools, without running your own MCP client.Part of MCP connector: [Client-side MCP helpers](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector#client-side-mcp-helpers)SDK helpers that convert between MCP types and Claude API types, for when you run your own MCP client, for example for local servers, prompts or resources.[MCP tunnels](https://platform.claude.com/docs/en/agents-and-tools/mcp-tunnels/overview)Connect Claude to MCP servers inside your private network over an outbound-only connection, with no inbound ports open.[Mid-conversation system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages)A system instruction added partway through a conversation, without changing the top-level system prompt or the cached prefix before it.Part of Mid-conversation system messages: [Mid-conversation tool changes](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages#mid-conversation-tool-changes)Offer or withdraw tools partway through a conversation without changing the tools array, so the cached prefix stays valid.Part of Mid-conversation system messages: [Turn-scoped system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages#turn-scoped-system-messages)A mid-conversation system message that applies only until the next user message, then stays in the history but renders nothing and costs no input tokens.[Multilingual support](https://platform.claude.com/docs/en/build-with-claude/multilingual-support)Claude works in many languages, with strong performance relative to English.[OpenTelemetry](https://platform.claude.com/docs/en/manage-claude/opentelemetry)Traces your Messages API requests, tool uses, and Managed Agents sessions with OpenTelemetry spans from the Claude SDK and the Claude API.Part of OpenTelemetry: [API tracing](https://platform.claude.com/docs/en/manage-claude/opentelemetry/api)OpenTelemetry spans that the Claude API sends to your observability platform for each model request and tool use that it runs.Part of OpenTelemetry: [SDK tracing](https://platform.claude.com/docs/en/manage-claude/opentelemetry/sdk)OpenTelemetry spans that the Claude SDK emits in your application for each request it sends and each tool that its tool runner runs.[Parallel tool use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/parallel-tool-use)Claude can call several tools in one response.[PDF support](https://platform.claude.com/docs/en/build-with-claude/pdf-support)Send PDFs to Claude so it can read the text, pictures, charts and tables in them.[Programmatic tool calling](https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling)Lets Claude call your tools from code in the code execution container, instead of one model round trip for each call.[Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)Reuses a cached prompt prefix from a recent request to reduce processing time and cost.Part of Prompt caching: [1-hour duration](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#1-hour-cache-duration)A 1-hour prompt cache lifetime, for a higher cache write price than the 5-minute default.Part of Prompt caching: [5-minute duration (default)](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#how-prompt-caching-works)The default prompt cache lifetime. Each use of the cached content refreshes it at no extra cost.Part of Prompt caching: [Automatic caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#automatic-caching)Prompt caching with one top-level `cache_control` field: the cache breakpoint goes on the last cacheable block and moves forward as the conversation grows.Part of Prompt caching: [Cache diagnostics](https://platform.claude.com/docs/en/build-with-claude/cache-diagnostics)Compares a request with your previous one and reports where the prompt prefix changed, to explain cache misses.Part of Prompt caching: [Explicit cache breakpoints](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#explicit-cache-breakpoints)Prompt caching with `cache_control` on individual content blocks, to choose exactly what is cached.[SDK middleware](https://platform.claude.com/docs/en/cli-sdks-libraries/middleware)A hook in the Claude SDKs that runs your code before each request is sent and after its response is received.[Search results](https://platform.claude.com/docs/en/build-with-claude/search-results)Content blocks that hold your own search results, with a source and title, so Claude can cite them the same way it cites web search results.[Service tiers](https://platform.claude.com/docs/en/api/service-tiers)Lets a request use your organization’s Priority Tier capacity.[Session budgets](https://platform.claude.com/docs/en/managed-agents/budgets)A hard spending limit in US dollars on one session, measured at public list prices.[Streaming refusals](https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/handle-streaming-refusals)A streamed response ends with `stop_reason` `"refusal"` when streaming classifiers stop it for a possible policy violation.[Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)Constrains Claude’s response to a JSON schema that you give, so the output is valid and parseable.[Task budgets](https://platform.claude.com/docs/en/build-with-claude/task-budgets)Tells Claude how many tokens it has for a full agentic loop, so it can plan its work and finish before the budget runs out.[Thinking](https://platform.claude.com/docs/en/build-with-claude/thinking)Claude works through a problem in thinking blocks before it writes its answer.Part of Thinking: [Adaptive thinking](https://platform.claude.com/docs/en/build-with-claude/thinking-steering-and-cost)Thinking mode in which Claude decides, for each request, whether to think and how much.Part of Thinking: [Extended thinking](https://platform.claude.com/docs/en/build-with-claude/extended-thinking)Manual thinking mode in which you set a fixed thinking token budget (`budget_tokens`) on each request.Part of Thinking: [Preserved thinking](https://platform.claude.com/docs/en/build-with-claude/preserved-thinking)Claude uses thinking blocks from earlier turns only if the current model can read them and nothing before them (system prompt, tools, earlier messages) has changed.[Threshold compaction](https://platform.claude.com/docs/en/build-with-claude/compaction-threshold)Automatic compaction: when a conversation reaches a token threshold, the API summarizes older context inside the request.[Token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting)Counts the tokens in a message before you send it to Claude.[Tool runner](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-runner)An SDK helper that runs the tool-use loop for you: it runs your tools when Claude calls them and sends the results back.[Tool search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool)Lets Claude search your tool catalog and load only the tool definitions it needs.[Vision (images)](https://platform.claude.com/docs/en/build-with-claude/vision)Claude can read and analyze images that you send to it.[Web domain restrictions](https://platform.claude.com/docs/en/managed-agents/tools-web-restrictions)Lists of allowed or blocked domains that control which sites the web search and web fetch tools can reach.[Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)A server tool that lets Claude get the full content of web pages and PDF documents at given URLs.[Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)A server tool that lets Claude search the web for current information.
