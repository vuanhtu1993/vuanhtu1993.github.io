Browse available middleware for different providers or contribute your own to the ecosystem. Learn more about how middleware works in the [middleware overview](https://docs.langchain.com/oss/javascript/langchain/middleware/overview) and how to use middleware with Deep Agents in the [Deep Agents docs](https://docs.langchain.com/oss/javascript/deepagents/customization#middleware).

Middleware enables context engineering, harness customization, and runtime safety controls. It is a useful extension point in LangChain and we love highlighting what the community builds with it:
