12. 🏆 Chứng Chỉ AI-901

Chuỗi tài liệu ôn thi Microsoft AI-901 (Azure AI Fundamentals) bằng tiếng Việt. Bao gồm lý thuyết, thực hành với Microsoft Foundry, và bộ câu hỏi luyện thi.

📄️Lộ Trình Ôn Thi AI-901

Lộ trình ôn thi AI-901 (Azure AI Fundamentals) bằng tiếng Việt. Tổng quan cấu trúc kỳ thi, so sánh AI-900 vs AI-901, hướng dẫn học khi hết free tier.

📄️Responsible AI — 6 Nguyên Tắc Microsoft

6 nguyên tắc Responsible AI của Microsoft: Fairness, Reliability, Privacy, Inclusiveness, Transparency, Accountability. Giải thích chi tiết kèm ví dụ thực tế và câu hỏi thi AI-901.

📄️AI Models — Hiểu Từ Gốc Rễ

AI model hoạt động thế nào? Phân loại model theo task, chọn model phù hợp, và các deployment options trong Microsoft Foundry (Standard, PTU, Managed Compute).

📄️AI Workloads — Bức Tranh Toàn Cảnh

Tổng quan các AI Workload trong AI-901: Text Analysis (NER, Sentiment, KPE, Summarization), Speech (STT/TTS), Computer Vision, Information Extraction, Generative AI và Agentic AI.

📄️Microsoft Foundry Portal — Tổng Quan

Microsoft AI Foundry Portal: Hub và Project structure, Model Catalog, deploy model, Playground, Foundry SDK. Cách bắt đầu khi có và không có Azure subscription.

📄️Build Chat App với Foundry SDK

Hướng dẫn build chat client app với Foundry SDK (Python): system prompts, streaming, chat history, và lab thực hành với free tier alternatives.

📄️Build Single AI Agent

Build Single AI Agent với Azure AI Agent Service: Agent anatomy (instructions, tools, threads, runs), tạo agent trong Foundry portal và Python SDK client.

📄️Agent Tools — Code Interpreter & File Search

Agent Tools trong Azure AI Agent Service: Code Interpreter (chạy Python sandbox) và File Search (RAG tự động). Hướng dẫn attach tools và lab thực hành.

📄️Text Analysis với Azure AI Language

Build Text Analysis app với Azure AI Language: NER, Sentiment Analysis, Key Phrase Extraction, Summarization. Hướng dẫn Python client + Foundry Tools.

📄️Speech AI — STT, TTS & Multimodal

Speech AI với Azure AI Speech: Speech-to-Text (STT), Text-to-Speech (TTS), và respond to spoken prompts bằng multimodal model (GPT-4o). Python lab.

📄️Computer Vision & Image Generation

Computer Vision & Image Generation với Azure AI Foundry: phân tích ảnh bằng multimodal model, OCR, object detection, và tạo ảnh với DALL-E 3. Python lab.

📄️Information Extraction — Content Understanding

Information Extraction với Azure Content Understanding: trích xuất từ documents, forms, images, audio, video. Python client và lab thực hành.

📄️Ôn Tập & Chiến Thuật Thi AI-901

Ôn tập toàn bộ AI-901: tổng hợp key concepts, bộ 30 câu practice questions, chiến thuật làm bài, và checklist trước ngày thi.
